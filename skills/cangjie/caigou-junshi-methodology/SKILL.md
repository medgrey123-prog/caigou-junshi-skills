# 菜狗军师 · 方法论

> 概念解决"为什么"，方法论解决"怎么做"。本文档是他的方法论全集——
> 每条方法论都贴合他的概念体系（见 caigou-junshi-concepts），可直接照抄执行。

---

## 使用方式：第二层，按用户决定才进入

本 Skill 是“概念 → 方法论 → 可选表达”三层流程的**第二层**。

### 前置条件

只在以下任一情况进入：
- 用户明确说“给我具体做法 / 方法 / 方案”；
- `caigou-junshi-concepts` 已完成概念解释，且用户确认要继续；
- 用户直接给出了足够具体的执行目标与约束。

如果没有问题背景，先回到概念层做最小澄清，不要直接丢出方法清单。

### 执行规则

1. 复述已确认的目标、场景、资源与限制；不清楚时最多追问 2 个会改变方案的问题。
2. 从下方方法中只选 **1–3 条**，说明每条分别解决什么；禁止大杂烩。
3. 每条方法必须改写成用户当下可执行的动作，给顺序、资源、风险与验证信号。
4. 交付后明确询问：**“是否需要把方案进一步写成菜狗军师风格的短视频/口播文案？”**
5. 只有用户需要，才调用 `caigou-junshi-expression` 进入第三层；表达层可做可不做，绝不默认附送。

### 方法论交付模板

```text
【你现在的问题】
<已确认的场景与目标>

【优先方法】
- Mx <名称>：为什么此刻适合

【行动顺序】
1. <具体动作>
2. <具体动作>
3. <具体动作>

【验证与风险】
- 看到什么说明方向对了
- 什么情况应停止/调整

要不要我把它写成口播/短视频脚本？（可选）
```

## 一、定位与起号

### M1. 找到自己三圆环法（找IP定位）
1. **你最想说的**——通过书写和自己对话，自己采访自己：
   - 如果明天互联网消失了，你最希望被别人记住的一个特质是什么？
   - 最近哪个爆款让你觉得他在胡说八道？如果是你讲，你最想推翻他哪一点？
   - 你过去的输出中，哪一次即使没有点赞你也想讲完？
2. **你坚持认为对的**——识别你的价值观（遇到争议时你下意识的直觉判断）。
3. **用户想听且能听懂的**——从情绪识别需求（什么内容让你愤怒/委屈/不屑，情绪指向哪里能量就在哪里）。
- **公式**：三个圆环的交集 = 你IP的命能。

### M2. 找自己三步落地
1. **书写自问**：用上面四个问题写下来，内核自然浮现。
2. **设计表达方案**：逻辑强→做拆解专线；直觉敏锐→做感悟专线；实战派→做带练专线。先做，再选最不纠结最流畅的。
3. **反馈迭代**：不要预判，用数据验证。最顺手 × 反馈最热烈的重合点 = 你的表达空间。
- **附加技巧**：找三个认可的博主，不抄文案，观察他面对争议的态度和表达结构，先模仿再调整。

### M3. IP起名两要义
1. **低成本**：零记忆成本——无特殊符号、无生僻字（思考是传播的敌人）。
2. **高密信息**：简单+直觉，用外延不用内涵（脑白金=送礼就送脑白金，蜜雪冰城=你爱我我爱你）。
- **验证**：起好名后发到评论区让朋友投票。
- **金句**：不要说服，要打动；不要打动，要感染。

### M4. 人设五步法
1. **贴标签**：外在形象+社会角色（方脸/一米九/宝妈/高管），找到特征并放大。
2. **找记忆点**：视觉锤+语言钉——视觉锤不一定要新奇（海参哥的脖套），语言钉必须简单重复魔性（怕上火喝…）。
3. **魅力反差**：挖掘普通人的英雄时刻、英雄的无助、男人的眼泪、女人的刚强。
4. **留缺点**：顶级人设都有缺点，缺点自带成长弧线（李云龙=泥腿子大老粗）。
5. **造梦者**：带入感（是普通人）+向往感（你想成为但成不了她）。

### M5. 人设三阶段（信任递进）
1. **可识别**：让观众三秒内回答"你是谁"（发型/穿着/道具/表达方式可设计）。
2. **可理解**：暴露缺点建立信任感；讲观点背后的故事和动机（"我为什么这么说"）。
3. **可投射**：让观众愿意把你放进他的情感地图——展示接近的体验、表达他无法说出的语言、活成他不敢成为的样子。

### M6. 人设三要素检查
- **人群**：你在对谁说话？（想聊职场晋升就别讲给大学生听）
- **情绪**：你想唤起什么？（情绪换情绪：你的焦虑/愤怒/恐慌用表情肢体传达）
- **动机**：你为什么表达？（观众先判断你的动机，再决定信不信）
- **模板**：我是一个（角色），面对的是（人群），通过（方式）为他们提供（核心价值）。

### M7. 自我诊断七问（人格结构扫描）
1. 你有没有允许自己展现本我？
2. 你敢不敢承认做IP就是为了火、为了被证明？
3. 你是否还没理清楚你是谁？
4. 你是否还在执意模仿别人？
5. 你要说什么、用什么样的方式说？
6. 你能承受哪些反应——被误解、被讨厌、被攻击？
7. 你是否试图包装一个别人喜欢的自己？

### M8. 错位竞争选题法（身份错位）
- **公式**：我的行业/身份 + 反差身份/场景 = 新内容定位
- **案例**：服装店长+大厨探店、外卖小哥+说唱、家庭主妇+潮流穿搭、酒庄庄主+红酒讲师
- **步骤**：①盘点可感知身份标签 ②找反差最大且你有素材的"化身" ③小成本测试3-5条 ④瓶颈期宁可停更思考，不乱发消耗权重。

## 二、选题与内容生产

### M9. 要素置换四宫格
- **公式**：什么主体（谁）× 用什么方式（怎么做）× 对谁（对象）× 做了什么事（事件）——四格只换一格。
- **案例**：主体置换（教做菜的是1岁孩子）、方式置换（用开奢侈品店的方式开奶茶店）、对象置换（给车针灸/给西瓜化妆）。
- **原则**：反差最大但逻辑自洽的才成立。

### M10. 反差三套路
1. **形象反差**：标志形象（丑角/萌妹/猛男/爷爷）+ 行为语言颠覆（萌妹玩说唱、猛男做家务）。
2. **场景反差**：标志场景（农村/野外/高档场所）+ 不相符行为（田间地头弹钢琴）。
3. **剧情反差**：日常情景铺垫 + 神转折结局（外卖美女爬六楼不是为了爱是为了还房贷）。
- **判断**：预期正向打破是爆款，反向打破是事故。

### M11. 预期违背四步法（完播率）
1. 设定日常情景。
2. 诱导观众代入、关心、思考（语言诱导+表演诱导双通道）。
3. 大胆反转（意料之外、情理之中）。
4. 连续埋点：每8-10秒一次预期违背，25秒内可做3次。

### M12. 爆款三步结构（叙事留白）
1. **预期误导**：开头用文字+情景立一个"常规剧情"的靶子。
2. **过程反转**：一句台词/一个动作打破预期，把悬念留在反转之后。
3. **结局留白**：不交代结果，停在"暧昧"处，逼观众联想与评论。
- **金句**：话别说完，事别讲完，与其直给，不如留白。

### M13. 选题心理闭环三要素
1. **情绪起点**：给谁看、激发他们什么情绪（羞耻/焦虑/恐惧/愤怒的唤起阈值更低）。
2. **冲突张力**：现实与期待的差距、我与外界的冲突、欲望与满足的冲突。
3. **角色代入**：向往感+带入感——标签圈定人群（00后宝妈/应届毕业生/30岁打工人）。
- **爆款选题公式**：老问题 + 新情绪 + 强带入感。

### M14. 选题训练三步
1. **建立心理机制词库**：刷视频问自己"我的心理什么时候被敲动"，收集"群体焦虑/身份丧失/误解/愤怒/自我合理化"等词。
2. **选题验证清单**：观众看完会有什么情绪？是否在讲更大的问题？是否和某类人群痛点有关？是否反常识？
3. **一题十写**：同一个选题写十个不同视角、不同情绪的表达版本。

### M15. 四类钩子+饵（开头攻势）
1. **好奇心**：做选择题/设悬念场景/说半句故事（"抓好奇心还是给福利？"）。
2. **暴力破场**：激烈冲突开场（名人出场必穿门、网红出场必叫头）+ 配人设。
3. **情绪激发**：骂式/愧疚式/反感式语言（"骂你为什么不减肥一定有力量"）。
4. **行动指令**：给明确动作指令，不给犹豫机会（"帮我看一下猫"）。

### M16. 钩子系统三步
1. **建钩子素材库**：记录①评论区高赞词 ②你停留瞬间的冲动+标题 ③生活中被勾住的瞬间。
2. **设内容主情绪**：问自己"希望观众看完有什么情绪"——焦虑/愤怒/释然/轻松/感动/羞耻。
3. **收集钩子句式**：练习"场景+情绪"结构（设置一个问题或场景+一个情绪刺激）。

### M17. 自我检讨五步法（涨粉爆款结构）
1. **交代现状**：年龄+身份+具体损失数字，先讲光环再讲低谷（"81年出生，今年43岁，创业失败负债接近300万"）。
2. **忆往昔光辉**：第一桶金故事。
3. **讲今日低谷**：有过辉煌再讲谷底，跌倒起伏才刺激人心。
4. **讲述心境**：情绪是传播的燃料，语气要不经意。
5. **经验复盘**：利他输出——少听成功者讲鸡汤，多听失败者讲经验。

### M18. 12字流量密码自查
- **先死后生**：极限任务+时间限制（挑战一百种职业、用一个树叶换一顿饭）。
- **先抑后扬**：身份反差+隐藏实力（CEO扮应聘者、小白误入职业赛）。
- **不劳而获**：低投入高回报的幻想满足（出门捡到白富美、和豪门男友恋爱）。
- **用法**：起号期围绕三公式批量生产选题，验证哪个在你赛道跑得动再放大。

### M19. 爽感四型选题法
- **解压爽**：修驴蹄/洗地毯/清藤壶式过程治愈。
- **发泄爽**：替观众怼同事、整顿老板、怼亲戚。
- **逆袭爽**：低起点+高成就（负债开局讲到身价过亿）。
- **发疯爽**：抽象、跳脱、反抗无聊世界。

### M20. 冲突六件套制造清单
- **关系冲突**：前任/情侣/夫妻
- **行为冲突**：藏找跑追躲
- **选择冲突**：内心两难，让观众站队
- **视听冲突**：大小/美丑反差（巨型雪媚娘、美女配丑老公）
- **价值冲突**：价格落差（66元钟薛高、4988元咖啡）
- **年龄冲突**：老头穿搭、小孩哥潮男

### M21. 七视角拍摄法
- 监控/行车记录仪（真实感+上帝视角）、食物视角（完播率90%+）、路人/偷窥视角（天然钩子）、同事视角（职场偷拍出干货）、宠物视角（绑摄像头）、男友视角（给镜头一个身份）、宝贝视角（身份对调）。
- **原则**：内容不变，视角一变，播放量翻百倍。

### M22. 口播五切换
1. **场景切换**：内外景来回拼接，解决画面呆板。
2. **表情切换**：夸张表情+情绪口播，消解说教感。
3. **打破知识诅咒**：专业人士别端着，用"发疯"式表达。
4. **情绪切换**：愤怒/恨铁不成钢式情绪用于垂类行业。
5. **人员/角色切换**：不同人设说同一件事（干得好/恨得好/换心情/年纪大的各说一遍）。

### M23. 普通选题做爆公式
- **情绪价值公式**：洞察冲突 + 营造向往 = 爆款播放。
- **操作**：①找缺失（缺爱/缺陪伴/缺理想关系）②给身份（口播+身份：理想妈妈/理想父母/理想爷爷）③造梦境（把用户不敢奢望的期待拍出来）。

## 三、数据与复盘

### M24. 数据人性翻译表
| 数据 | 用户心理 | 提升方法 |
|------|---------|---------|
| 点赞 | 最低门槛认同（嗯是这样） | 设置情绪锚点+金句+价值感 |
| 评论 | 表达欲释放（我想被看见） | 挑战认知一致性的冲突内容；保持坚定立场 |
| 收藏 | 不想失去（对未来更好的期许） | 强调信息有效性和未来可用性，制造稀缺急迫感 |
| 转发 | 社交货币（当嘴替/当名片） | 替用户说出不敢说的话；让转发显得有格调 |

### M25. 数据反推用户心理三步
1. **是谁在点赞**：刚毕业年轻人/三线城市宝妈/35岁焦虑中产？
2. **为什么点赞**：被什么情绪带动——焦虑/同情/愤怒/无奈？
3. **行为在表达什么**：观察评论和高赞内容，找到激发行为的原始情绪。

### M26. 新手复盘动作清单
- 不要想平台行不行，想你的标题有没有勾人。
- 不要想算法是否打压你，想怎么提高五秒完播。
- 不要委屈说用户不理解你，想怎么让用户愿意听你。
- **原则**：从受害者思维跳出来，变成主体性思维。

## 四、利他与内容价值

### M27. 利他三步走
1. **定位他者**：他是谁（同行/客户/某一类人）？不要用人口学标签，描述他的心理处境（小白/焦虑找方向/瓶颈期/找新增长点）。
2. **理解他者**：他此刻最焦虑什么？他最希望被理解什么？他最不能接受的认知挑战是什么？
3. **输出匹配**：在他想听的内容里选你想讲且能讲好的；你有100个知识点观众只需要一个，那就持续讲重复讲。

### M28. 四种投射自查
- **认知型投射**：你知道就默认观众也知道 → 降低认知门槛。
- **价值观投射**：认为你的观点代表普罗大众 → 尊重个体处境差异。
- **情绪型投射**：更想表达自己的情绪 → 这是发泄不是洞察。
- **经验型投射**：用自己的经历当通用模板 → 别人没经历过你的处境。

### M29. 四种利他类型（按数据目标选）
- **认知型利他**（要完播/收藏）：讲干货方法——用户收藏是在收藏自己的进步。
- **情绪型利他**（要评论/转发）：讲共鸣故事——让用户觉得被理解。
- **社交型利他**（要点赞/转发）：讲价值观态度宣言——满足身份展示。
- **工具型利他**（要搜索/收藏）：给模板清单操作指南——满足掌控感。

### M30. 四翻译法
1. **语言翻译**：专业数据→生活语言。
2. **情境翻译**：抽象理念→熟悉场景。
3. **情绪翻译**：用观众能听懂的共鸣代替你的认知产出。
4. **视角翻译**：从"我在说什么"到"观众想听什么、听到了什么"（不说"做短视频要了解用户心理"，说"为什么别人没你好看但比你火"）。

## 五、AI 提效

### M31. AI提效五句式
1. "回答问题之前，先明确定义并跟我确认。"
2. "如果你是XX（名人/目标角色），你会怎么回答这个问题？"
3. "你需要先分析前提再给出答案。"
4. "你需要我补充什么信息吗？"
5. "你对需求的分析还不够透彻，请再深度一点、再批判一点。"

### M32. 约哈里之窗四区沟通法
- **公开区**（都知道）：当员工——明确任务、清晰结构、给边界。
- **隐藏区**（你知道AI不知道）：当伙伴——自我暴露主动喂养（你是谁/目标/限制/目的）。
- **盲目区**（你不知道AI知道）：当老师——首次提问不给限制，给反馈不给评价（"受众可能太广泛，能不能更精准"），PUA它："太宏观了，给一句话示范"。
- **封闭区**（都不知道）：当同事——用设问共创（"如果目标受众是老板，他们会关注什么？"）。

### M33. 元认知公式三层
1. **需求拆解**：表层需求（要爆款文案）→真实需求（客户咨询/好口碑）→需求背后的需求才有价值。
2. **指令设计**：给明确指令（"转化型爆款视频：看了视频就来买"）。
3. **结果校准**：把自己当严格追问的老板——给我案例、给我数据、再给我10条样本。

### M34. AI防幻觉四招
1. **交叉验证**：同一问题开5个AI（DeepSeek/Claude/GPT/豆包）各写一遍互查。
2. **提示词约束**：打"提示词疫苗"——"所有案例数据必须真实，标注来源；无法确认就标'无数据来源'；拒绝所有绝对化表述"。
3. **场景分级**：医疗/法律=一级风险高度警惕；写文案=开放度高。
4. **靠人判断**：出现不可思议的数据、不认识的"专家文献"时=它在胡说。

### M35. 克隆博主智能体五步法
1. 批量提取大V爆款文案（优先高赞）。
2. 让AI按六维框架分析爆款要素：叙事逻辑/文案框架/语言风格/情绪钩子/人设体系/目标人群。
3. 设定智能体目标并生成需求文档（人物设定+技能+工作流程+输出要求）。
4. 复制需求文档到扣子（Coze）平台测试。
5. 用对比模式做细节修改校准。

### M36. 给AI建团队
- 按任务类型分别设定专属智能体：风格文案、故事逻辑、心理洞察、商业内容、运营建议、个人风格、选题、爆款结构提取、聊天——每个智能体只干一类活。

## 六、商业与变现

### M37. 祛魅决策三问（面对光环人物）
1. 他为什么找我？（我有什么他需要的价值，还是他只需要我的仰慕？）
2. 这个"免费"背后谁在付费？（咨询/陪聊/人情都是成本）
3. 我心动的那一刻，主动权在谁手里？
- **结论**：答案指向"我只是想要他的光环"→拒绝。

### M38. 借船出海冷启动
1. 借大平台/大IP背书拿下首批客户。
2. 薪酬/利益设计自己只留三分之一，用利益绑定信任。
3. 不挑战人性：用机制避免诱惑（小黑屋放钱测试），而非考验人性。
4. 用人所长、充分授权。

### M39. 穿越平台周期四步法
1. **风格定魂**：找到独树一帜的人设风格，不随平台迁移丢失。
2. **爆款重复**：验证过的爆款系列跨年复推（深圳卫健委"女护士"系列）。
3. **趋势迭代**：新平台/新形态起来时用"老魂+新壳"跟进。
4. **情感升维**：从消遣型内容升级到让人"哭"的情感内容。

### M40. 记录生活双风口
- **记录美好生活**：真实粗糙>精致质感，场景越真实越好（超市/生日/日常）。
- **寻找美好心灵**：焦虑经济→疗愈经济（禅修/冥想/正念/国学/助眠）——制造焦虑赚小钱，缓解焦虑赚大钱。
