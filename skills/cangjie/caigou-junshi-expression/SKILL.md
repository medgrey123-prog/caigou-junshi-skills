# 菜狗军师 · 表达与文案仿写

> 不是抄他的句子，是复用他的表达结构。

## 一、表达 DNA（五段结构）

菜狗军师所有视频文案遵循同一骨架，可直接套用：

```
【钩子开场】3秒内用提问/反常识/冲突抓住注意力
   ↓
【概念引入】给现象起一个名字（造概念），或引用一个心理学/传播学概念
   ↓
【案例拆解】讲一个具体的人/事/数据，验证概念
   ↓
【方法落地】给出可照抄的步骤/公式/清单
   ↓
【金句收尾】一句可截图传播的总结性金句
```

### 各段写法细则

**① 钩子开场（0-5秒）——五种开场武器**

| 类型 | 公式 | 示例 |
|------|------|------|
| 提问式 | 抛一个扎心问题 | "你是不是越做越痛苦了？" |
| 反常识式 | 说一句违背直觉的话 | "努力是做IP最长的弯路" / "流量惩罚努力的人" |
| 测试式 | 让观众先做一个判断 | "三秒钟测试一下你的自命与天赋" |
| 场景代入式 | 描述一个熟悉场景 | "你妈妈逼着你吃过饭吗" |
| 冲突宣言式 | 直接亮立场 | "IP不要拥抱所有人，而是敢得罪和拉黑你讨厌的人" |

**② 概念引入——给现象命名**

这是菜狗军师最核心的表达习惯：**不直接讲方法，先给概念**。
- 从心理学借概念：外归因、认知失调、镜像神经元、蔡格尼克效应、宜家效应、出丑效应、预期违背、贝叶斯预测
- 自己造概念：心智凝结、自我图示、情绪开关、远近理论、要素置换、心理语境、情绪锚点
- 借经典名言：反者道之动、弱者道之用、大音希声、破山中贼易破心中贼难

引入公式：`"心理学有一个概念叫XX，它说的是……"` 或 `"我给你一个词：XX。"`

**③ 案例拆解——具体到可感知**

- 有数字：年龄、金额、播放量、涨粉数（"涨粉180万""点赞14735"）
- 有人名：王老吉、罗永浩、大圆哥、于文亮、付航
- 有场景：妈妈煮阳春面、三个朋友点菜、花一万块抽奖
- 一句话原则：**先讲光辉再讲低谷、先讲失败再给希望**

**④ 方法落地——必须给"能抄的"**

菜狗军师的方法论永远可操作：三步法、五步法、四个问题、一个公式。
格式偏好：`第一步……第二步……第三步……`，或 `公式：A+B=C`。

**⑤ 金句收尾——可截图传播**

金句结构：
- 对仗式："越强越不被信任，越弱越容易被喜欢"
- 否定式："不是……而是……"（"不是方法错了，而是卡住你的根本不是不会做"）
- 反常识式："完成比完美重要，过度准备就是一种逃避"
- 升华式："我们不快，但我们要更稳"

## 二、语言风格（可模仿的声音）

| 维度 | 特征 | 示例 |
|------|------|------|
| 句式 | 短句为主，口语化 | "听不懂没关系" "过来举一个例子" |
| 人称 | 大量用"你"，直接对话 | "我给你一个建议" "你先别着急" |
| 连接词 | "但是""你会发现""说白了" | "但是你必须残忍地告诉你" |
| 修辞 | 比喻密集（流量池钓鱼、史莱姆、灯塔） | "情绪是你最好的鱼钩" |
| 数字 | 精确到个位 | "95%的收藏夹都是用来吃灰的" |
| 态度 | 敢下判断、敢得罪人 | "你只需要做一件事情：反求诸己" |

### 三组招牌句式（直接复用）

1. **提问开场三连**："我问你一个问题……你有没有发现……你想象一下……"
2. **概念引入**："心理学有个概念叫XX""我给你讲一个反直觉的真相""这句话翻译一下就是……"
3. **方法收束**："总结起来就是……""你只需要记住三个字：……""回到开头那个问题，答案只有一个"

## 二½、新增表达武器库（2026 第二批蒸馏）

### 五个万能钩子句式（开头/中段通用）
| 钩子 | 句式模板 | 案例 |
|---|---|---|
| 恐惧 | "X 的人最后都 Y 了" | 怕上火喝王老吉 |
| 利益/利他 | "我花 X 万学到的 Y，今天全给你"/"千万不要在家里装以下八样东西" | 10万学费技巧 |
| 焦虑 | 直接点名焦虑源（减肥/失业/年龄/婚恋/买房） | "35 岁被裁你在干什么" |
| 窥探 | "X 到底长什么样"/挑战类（200 元盲盒/辞职体验 100 种职业） | 遮遮掩掩最勾人 |
| 权威 | 借势（"清华推荐书单"/"明星都在穿"） | 羊群效应最快 |

### 5 秒开头四方向（按威力排序，择一即可）
1. **预期违背**："好懂，但和我想的不一样"——先给熟悉感再推翻
2. **自我参照**：精准点出人群/处境/痛苦（"做 IP 卡了半年的人，问题都不在内容"）
3. **信息缺口**：抛问题不给答案（"我删了 200 条视频才明白这件事"）
4. **冲突**：断言/对立观点/刺激画面（"越干货越没流量"）
- 底层公式：简单（认知流畅）+ 值得看（信息价值）。

### 掏兜感消除话术（转化类内容）
- **换位置**：不说"我建议你……"，改说"我当时也踩过这个坑，后来我这么干的……"
- **换顺序**：先给完价值再闭嘴（试用装逻辑），结尾不喊买，让他自己要
- **划边界**："这个产品不适合三种人，第一种就是……"（双面论证反而增信任）

### 诉苦/脆弱叙事话术
- 开场不控诉不卖惨，只描述具体处境和动作（"那天我在车里坐了半小时"）
- 落点必须给出去（"后来我是怎么走出来的，这三点你可以直接用"）
- 禁止：精致场景 + 齐整口音 + 强烈装饰（一有表演感就翻车）
- 自检：观众看完更负担还是更轻松？更负担就是自恋不是给予

### 站队表达法（人性暗面第三条）
- 去掉所有中庸表达，先想清楚"我明确反对什么"
- 例句模板："别再怪自己了——是 XXX 制度反人性，我今天教你怎么绕过去。"
- 原理：旗帜鲜明才有支持者，当嘴替才有转发

### 新金句库（可直接引用/改造）
- "流量的敌人是深刻、复杂、系统；流量的爱人是简单、人性和价值。"
- "流量最大的敌人是你的优势。"（天之道：损有余而补不足）
- "80 分发出去，好过 100 分压三天。"
- "爆款 = 真需求 × 精准供给。"
- "你不是不会表达，你是没有结构。语言是思维的成型工具。"
- "流量是平台的，信任才是你的。"
- "小 = 边界清晰，偏 = 竞争稀薄，稀 = 个人独特。"
- "人设的本质是管理用户的投射。"
- "没有智慧的善良，比明摆着的恶意更可怕。"
- "掏兜感一出现，信任就崩塌——用户拒绝的从来不是商品，是"被卖"这个动作。"

## 三、仿写工作流（可选的第三层）

**默认不直接仿写。** 先由 `caigou-junshi` 总入口完成提问、概念解释与方法论方案；仅在用户明确说“要脚本 / 要口播 / 要按菜狗军师的表达方式写”时，才进入这一层。

开始前补齐以下信息；已有信息不重复问，每轮最多问 3 个：

1. **内容目标**：涨粉、建立人设、获得咨询、卖产品，还是表达观点？
2. **受众与场景**：想让谁在什么情境下被打动？
3. **表达边界**：可用的真实案例/数据、不能碰的话题、时长与平台。

完成后按以下步骤执行：

1. **定主题**：把用户目标翻译成一个明确主题（IP/流量/AI/心理等）。
2. **承接概念**：优先使用已在概念层确认的概念；没有时才从概念库选择。
3. **选钩子**：从五种开场武器中选一种（优先提问式或反常识式）。
4. **配案例**：从案例库找匹配案例，或只用用户提供的真实经历；不能编造数据、经历或权威背书。
5. **落方法**：写成三步、五步或公式，并与方法论层保持一致。
6. **造金句**：用对仗/否定式收束，但不为了金句牺牲事实。

完成标准：脚本同时具备“钩子—概念—案例—方法—收尾”，且用户的目标、受众、证据和边界都被明确回应。

输出格式（直接给用户）：

```
【开场】
（钩子，3秒内）
【正文】
（概念→案例→方法，口语化短句）
【金句】
（一句可截图的话）
```

## 五、典型范文（从原素材蒸馏）

**范文1（反常识+概念+案例+方法+金句）：**
"做IP有个残忍的真相：流量惩罚努力的人。你是不是越做越痛苦了？《道德经》里讲，反者道之动，弱者道之用。三个方向让你少走十个月弯路：第一，反求诸己——越向外求越迷失，越向内求越清晰；第二，去我执——你不是没有观点，你只是要学怎么让别人愿意听；第三，敢示弱——越强越不被信任，越弱越容易被喜欢，情绪系统处理信息比理性快300毫秒，你话还没讲完，用户已经决定要不要喜欢你。传播的力量从来不是越强越好，而是越弱越近。"

**范文2（提问+利他+四投射+三步）：**
"你妈妈逼着你吃过饭吗？以自我为出发的善意，反而让人难受。你的内容都是干货但没流量，说明你不理解什么是真正的利他。四种投射你中了几个：认知型投射、价值观投射、情绪型投射、经验型投射。利他三步走：定位他者——不要用人口学标签，要描述他的心理处境；理解他者——他此刻最焦虑的是什么？他最希望被理解的是什么？输出匹配——在他想听的内容里，选你想讲且能讲好的。焦虑的人不需要被教育，只想被安抚。当你从以自我为中心的善意走向以他者为中心的共情，流量会追着你跑。"
