# 菜狗军师 Skills：询问式内容、IP、AI 与增长决策系统

> 基于菜狗军师抖音账号 **68 条作品**（67 个视频 + 1 篇长文）提取的认知框架、操作方法与表达结构。
>
> 这不是一句提示词，也不是模仿某个人的口头禅；它是一套让 AI **先理解问题、再解释概念、经确认后给方法、按需要才写内容** 的对话式系统。

## 你会得到什么

```text
一个真实问题
    ↓
① 最小澄清：目标、场景、资源与限制
    ↓
② 概念诊断：为什么会卡住？应该怎样重新看问题？
    ↓  （用户确认是否继续）
③ 方法方案：接下来具体怎么做？如何验证？
    ↓  （用户决定是否需要）
④ 内容表达：写成短视频、口播或文案
```

| Skill | 职责 | 什么时候使用 |
|---|---|---|
| **`caigou-junshi`** | **统一入口**：管理完整的询问式三层流程 | 不知道从哪里开始，或要分析内容/IP/AI/增长问题时 |
| `caigou-junshi-concepts` | **概念层**：解释“为什么”，用核心概念重新诊断问题 | 想改变看问题的角度，尚未急着要做法时 |
| `caigou-junshi-methodology` | **方法层**：把概念变成行动、验证与调整机制 | 已确认目标，需要可执行方案时 |
| `caigou-junshi-expression` | **表达层（可选）**：把方案写成口播、短视频或文案 | 明确需要内容脚本/文案时 |

## 与普通“提示词包”的区别

- **不一上来给万能清单**：每轮最多问 3 个真正会影响判断的问题。
- **概念先于方法**：先看清真实矛盾，再决定怎么做。
- **方法要经用户确认**：不默认把方案塞给你。
- **脚本是可选项**：不是所有问题都需要被写成短视频。
- **不编故事**：没有来源的数据、案例和经历，必须标为假设或示例。

## 适用问题

- 内容为什么没流量、怎么选题、怎么做钩子；
- 个人 IP 如何定位、人设如何建立、怎么冷启动；
- 如何理解用户心理、提升收藏/评论/转发；
- 如何用 AI 做内容、提需求、减少幻觉；
- 如何做复盘、增长、商业化与决策。

## 安装

### 通用 AI Agent

把整个仓库下载/克隆到你的 Agent 可读取的 Skills 目录：

```bash
git clone https://github.com/medgrey123-prog/caigou-junshi-skills.git
```

然后告诉你的 Agent：

```text
请阅读 caigou-junshi/SKILL.md，按其中的询问式流程工作。
```

不同工具的 Skills 安装目录不同，请按各自工具的文档放置。仓库只使用标准 Markdown，不依赖某个特定 Agent。

### Hermes Agent

复制四个文件夹到 Hermes 的 skills 目录即可：

```text
<hermes-home>/skills/cangjie/
├── caigou-junshi/
├── caigou-junshi-concepts/
├── caigou-junshi-methodology/
└── caigou-junshi-expression/
```

重开一个 Hermes 会话后，Skill 会被自动发现。

## 怎么开始对话

直接说真实问题即可：

```text
我做了很多干货短视频，但没有流量。请用菜狗军师的询问式流程帮我分析。
```

或：

```text
我想做个人 IP，但说不清定位。先不要给我脚本，先帮我跑概念诊断。
```

当你想继续时，再说：

```text
继续，给我可执行的方法。
```

只有你想要内容时再说：

```text
把上面的方案写成一条 60 秒短视频口播。
```

## 内容范围

### 概念层

包含但不限于：心智凝结、自我图示、无动机不人设、外归因与内归因、预期违背、情绪开关、数据人性翻译、镜像共鸣、要素置换、错位竞争、AI 元认知、约哈里之窗、苦难资产化等。

### 方法层

包含 IP 三圆环定位、人设五步、错位竞争选题、要素置换、反差与预期违背、钩子系统、选题训练、数据复盘、利他三步、AI 提效与防幻觉、冷启动与穿越平台周期等。

### 表达层

提炼五段结构：

```text
钩子开场 → 概念引入 → 案例拆解 → 方法落地 → 金句收尾
```

它是结构参考，不是强制模板；事实不足时不得虚构案例与数字。
